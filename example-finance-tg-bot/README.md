# Telegram Finance Bot

Telegram бот для учета личных финансов с использованием SQLite базы данных.

## Установка

### 0. Перейдите в терминал в папке с проектом

```bash
cd example-finance-tg-bot
```

Или нажать ПКМ на папке (`example-finance-tg-bot`) с проектом и выбрать "Открыть в терминале".

### 1. Клонирование и установка зависимостей

```bash
npm install
```

### 2. Получение Telegram Bot Token

1. Найдите [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в файл `.env`

### 3. Настройка переменных окружения

Отредактируйте файл `.env`, вставьте полученный токен в `TELEGRAM_TOKEN`. Если при запуске пишет, что `3000` порт занят, то можно изменить `PORT` на любой другой.

## Запуск

```bash
npm start
```

После запуска:

- Бот будет доступен в Telegram
- Веб-интерфейс будет доступен по адресу: http://localhost:3000/

## Перезапуск бота

1. Отключить старый сервер: `Ctrl + C` в том же терминале, в котором уже был запущен бот.
2. Запустить бот заново: `npm start`

> Возможно, при перестроении базы, старые данные уже не релевантны.
> Тогда стоит
>
> 1. Остановить сервер: `Ctrl + C`
> 2. Удалить базу данных: `rm finance.db` (или просто удалить файл `finance.db`)
> 3. Запустить бот заново: `npm start`
>
> База данные будет пересоздана с нуля.

## Частые проблемы

### Порт уже занят

Если у вас уже запущен сервер на порту `3000`, то нужно остановить его или выбрать другой `PORT` в `.env` файле.
Если больше ничего на этом порту запущено быть не должно, то нужно посмотреть, что запущено на этом порту и остановить это приложение.

Пример для Linux:

```bash
lsof -i :3000
# пример вывода:
# COMMAND   PID USER   FD   TYPE             DEVICE SIZE/OFF NODE NAME
# node    12345 user   21u  IPv6 0x1234567890abcdef      0t0  TCP *:http-alt (LISTEN)
```

Тогда нужно остановить процесс:

```bash
kill -9 <PID> # где <PID> - это PID процесса, который запущен на этом порту (в примере выше это `12345`).
```

Пример для Windows я не знаю.
